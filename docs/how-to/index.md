# How-to Guides

Focused, practical recipes for common tasks with Dealbreaker.

- [CLI & Scripting](/how-to/cli-and-scripting) — JSON output, replaying solutions, batch benchmarks, and long-lived `serve` processes.
- [Configure Fair Hints & Cancellation](/how-to/fair-hints) — tune sample counts, pass unknown cards (`"?"`), set timeouts, and cancel searches.
- [Solve Points Games](/how-to/points-games) — maximize scores in Poker Squares / Cribbage Squares or target a minimum score.
- [Tune Search Speed & Budgets](/how-to/tune-search) — pick strategies, set state/time limits, and adjust heuristic weights.
- [Extend Rules with Rust Hooks](/how-to/custom-rust-hooks) — add custom Rust logic via `dealbreaker::Hooks` when JSON isn't enough.
- [Embed in C, Swift, or Kotlin](/how-to/mobile-and-native) — build static/shared libraries and Apple XCFrameworks from `dealbreaker-ffi`.
