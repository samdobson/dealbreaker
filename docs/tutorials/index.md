# Tutorials

Hands-on, step-by-step guides to help you learn Dealbreaker by doing.

- [Your First Solve](/tutorials/first-solve) — install Dealbreaker and solve your first deal in under 2 minutes (CLI, JavaScript, Python, or Rust).
- [Build a Custom Game in JSON](/tutorials/custom-game) — create a brand-new solitaire variant from 15 lines of JSON, validate it in your editor, and solve it.
- [Add Fair Hints to a Web App](/tutorials/web-app-hints) — wire up `WorkerSolver` in a browser so hints run off the main thread and never peek at face-down cards.

::: tip Just want to play around?
You don't need to install anything—open the <a href="/dealbreaker/demo/" target="_self">Live Web Demo</a> to solve deals and live-edit rules JSON right in your browser.
:::
